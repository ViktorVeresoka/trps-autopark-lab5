# Архітектура навчального репозиторію

Проєкт продовжує рішення ADR-01 з ЛР 4: модульний моноліт із шарами Presentation, Application, Domain та Infrastructure, із залежностями до доменного ядра.

У навчальній реалізації пакет `domain` зберігає сутність транспортного засобу та правила пробігу й технічного обслуговування. `application` описує порт репозиторію й сценарій реєстрації/обліку пробігу. `infrastructure` містить тимчасовий адаптер у пам'яті. Майбутній API та SQL-адаптер можна додати без зміни доменних правил.

Ролі й повний web API залишаються у межах попередньої наскрізної моделі. Цей репозиторій реалізує перший перевірюваний доменний вертикальний фрагмент, а не заявляє про готовий production-сервіс.
