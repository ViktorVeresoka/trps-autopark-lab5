# Локальний Git-процес

1. `main` містить базову модель автопарку та інтегровану перевірку планового ТО.
2. `feature/maintenance-schedule` додає попередження про ТО: прострочене, потрібне зараз, наближається (не більше 500 км) або ще не потрібне.
3. Щоб відтворити конфлікт, у `main` та `feature/maintenance-schedule` окремо змінено метод `Vehicle.maintenance_status`. Під час злиття Git позначив обидва варіанти маркерами конфлікту. Файл вручну замінено узгодженою чотиристанною логікою; інтеграцію зафіксовано merge-комітом.
4. `feature/expense-report` містить облік і зведення витрат за категоріями. Гілка призначена для окремого pull request.

Перед злиттям запускається `python -m unittest discover -s tests -v`. Workflow `.github/workflows/tests.yml` запускає той самий набір перевірок після push і для pull request у GitHub Actions.
