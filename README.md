# Автопідприємство

Навчальний проєкт для обліку транспорту малого або середнього автопідприємства. Робота продовжує модель варіанта 4 з лабораторних робіт № 1-4.

## Призначення

Система допомагає диспетчеру планувати рейси, механіку контролювати пробіг і технічне обслуговування, бухгалтеру вести витрати, керівнику готувати звіти, а водієві переглядати призначені рейси.

## Структура

- `src/autopark/domain` - предметні сутності та правила.
- `src/autopark/application` - сценарії використання та порти.
- `src/autopark/infrastructure` - адаптери до сховищ та зовнішніх сервісів.
- `tests` - автоматизовані перевірки.
- `docs` - проєктні рішення й експлуатаційні нотатки.

Внутрішні правила не залежать від інтерфейсу, бази даних або зовнішніх сервісів. Це відповідає модульному моноліту з архітектурного рішення ADR-01 у ЛР 4.

## Технології

Python 3.11 або новіший, Git, GitHub Actions. На цьому навчальному кроці використовується in-memory адаптер, без зовнішньої бази даних.

## Запуск

```powershell
python -m unittest discover -s tests -v
```

Щоб використати домен у скрипті, додайте `src` до `PYTHONPATH` або встановіть проєкт у режимі розроблення.

## Контроль версій

Репозиторій містить історію послідовних комітів, гілку розроблення технічного обслуговування, приклад локального конфлікту та GitHub workflow. Докази команд і результати наведено у звіті до ЛР 5.
## Фрагмент обліку витрат

Модуль витрат підтримує бухгалтера та звітність керівника. Він групує витрати за категоріями й датами, не звертаючись до конкретної СУБД. Для навчальної демонстрації застосовано in-memory адаптер.
